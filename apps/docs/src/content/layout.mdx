## Choose a primitive

Need a wrapper? Start with Box. Use Stack for vertical groups, HStack for
horizontal groups, Flex for custom alignment, and Grid for columns. Container
constrains and centers page content. Use Text and Heading for meaningful text
instead of styling a generic Box. Prefer TanStack Router Link for application
navigation; registry Link is optional and excluded from the default lint policy.
Select a component below to see a live preview and copy its source.

- [Box](/components/box): Div by default; `as` selects a semantic element with
  tag-specific events and refs. Applies default box sizing and minimum inline
  size.
- [Flex](/components/flex): Flex layout; customize direction and alignment with
  `xstyle`.
- [Stack](/components/stack): Column flex layout with four spacing units between
  children.
- [HStack](/components/hstack): Row flex layout with centered cross-axis
  alignment and four spacing units between children.
- [VStack](/components/vstack): Column flex layout with four spacing units
  between children.
- [Grid](/components/grid): Grid layout; set columns and rows with `xstyle`.
- [Center](/components/center): Flex layout centered on both axes.
- [Container](/components/container): Fluid page wrapper centered up to 90rem;
  use `fluid` for full width or `xstyle` to override maximum width and padding.
- [Absolute Center](/components/absolute-center): Center content within a
  positioned parent.
- [Bleed](/components/bleed): Extend content into a parent's inline padding.
- [Float](/components/float): Position content over a parent's corner.
- [Wrap](/components/wrap): Lay out items in wrapping rows.
- [Link](/components/link): Native anchor with `href`, `target`, `rel`,
  `download`, ref, and native keyboard behavior.
- [Text](/components/text): Native paragraph without forced visual defaults.
- [Blockquote](/components/blockquote): Long-form quotation.
- [Em](/components/em): Emphasized text.
- [Highlight](/components/highlight): Highlight matching words.
- [Mark](/components/mark): Marked text.
- [Prose](/components/prose): Readable long-form content.
- [Codeblock](/components/codeblock): Preformatted code with horizontal
  overflow.
- [Heading](/components/heading): `h2` by default; `as` selects `h1` through
  `h6` independently of visual size.

## Native semantics

Box defaults to div. Its `as` prop selects the native tag and its event/ref
types. Input size, image width and height, and meta content remain native
attributes. Use `xstyle` for styling. Heading restricts `as` to heading tags.
Link performs native navigation by default. Use TanStack Router Link directly
for application navigation. Native anchors and framework links remain valid;
there is no requirement to wrap them in registry Link. If deliberately using
registry Link, pass a framework Link through `render` to preserve navigation.

### Semantic components

```tsx
import { Box } from "@/components/ui/box"
import { Heading } from "@/components/ui/heading"
import { Link } from "@/components/ui/link"
import { Text } from "@/components/ui/text"
import * as stylex from "@stylexjs/stylex"

const styles = stylex.create({ article: { padding: "1rem" } })

export function Article() {
  return (
    <Box as="article" xstyle={styles.article}>
      <Heading as="h2">Getting started</Heading>
      <Text>Copy the components into your application.</Text>
      <Link href="/docs/installation">Installation guide</Link>
    </Box>
  )
}
```
