Use `stylex.create` for styles. Pass a style to a copied component through
`xstyle`. The component applies this style after its defaults and variants. For
native HTML or framework elements, spread `stylex.props(...)` instead. Do not
pass CSS properties or styling aliases as JSX attributes.

```tsx
import { Box } from "@/components/ui/box"
import { tokens } from "@/styles/tokens.stylex"
import * as stylex from "@stylexjs/stylex"

const styles = stylex.create({
  card: {
    backgroundColor: tokens["--card"],
    borderRadius: tokens["--radius-lg"],
    paddingBlock: "1rem",
    paddingInline: {
      default: "1rem",
      "@media (min-width: 768px)": "2rem",
    },
  },
})

export function Card() {
  return (
    <Box render={<section />} xstyle={styles.card}>
      Content
    </Box>
  )
}
```

Create responsive rules, state selectors, and themes inside `stylex.create`. Use
semantic tokens instead of literal colors. Pass an array to `xstyle` to combine
styles. Later entries override matching properties. Use `className` for
integration with external CSS. This documentation app uses only StyleX for
styling.

`Box` is the default container. It sets box sizing and minimum inline size. Use
`render` for semantic native tags. Choose `Flex`, `Stack`, `Grid`, or `Center`
for layouts with additional defaults. Use `Heading`, `Text`, or `Link` for text.
