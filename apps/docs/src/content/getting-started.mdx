Yopem UI copies component source into your React and TypeScript project. You can
edit those files directly. There is no runtime component package.

Set up your project once. Then choose the components your app needs.

<span id="setup" />

## 1. Set up your project

Follow the [installation guide](/docs/installation) to configure StyleX for your
framework. It covers supported projects, the init command, and build checks.
Return here when your app completes a production build.

If you already completed installation, choose a component below. You do not need
to run init again.

<span id="install-button" />

## 2. Choose a component

Browse [Components](/components) and open the component you want. Each page has
an install command, live previews, and usage examples.

Run its install command from your project root. For example, if you choose
[Button](/components/button):

```sh
bunx --bun @yopem-ui/cli add button
```

The CLI copies the selected component source and installs its dependencies.

<span id="use-button" />

## 3. Use your component

Copy a usage example from the component page into your app. Import from the
local file that the CLI installed. The init command maps `@/*` to `src/*`.

For Button, a usage example looks like this:

**src/components/save-button.tsx**

```tsx
import { Button } from "@/components/ui/button"

export function SaveButton() {
  return <Button variant="outline">Save changes</Button>
}
```

Render `SaveButton` on a page in your app. Check its padding, border, and hover
state. Press Tab to check that the keyboard focus ring is visible.

If styles are missing, return to the
[installation checks](/docs/installation#check).

<span id="customize" />

## Customize when needed

Check your component's documentation for variants and props. For a local style
change, pass `xstyle`. This Button example changes its border radius:

**src/components/save-button.tsx**

```tsx
import * as stylex from "@stylexjs/stylex"
import { Button } from "@/components/ui/button"

const styles = stylex.create({ button: { borderRadius: "999px" } })

export function SaveButton() {
  return <Button xstyle={styles.button}>Save changes</Button>
}
```

Use tokens to change styles throughout your app. Edit the copied source when you
need to change behavior. Keep accessible names, keyboard behavior, disabled
states, and focus indicators.
