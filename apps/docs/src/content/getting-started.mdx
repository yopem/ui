## What you need

- A React application that uses TypeScript.
- React Router with Vite, TanStack Start, Next.js, or Astro.
- Permission to add packages and files to the project.

Yopem has no runtime component package. Initialize StyleX once. Then install
component source with the CLI.

<span id="setup" />

## 1. Set up StyleX

Run `bunx @yopem-ui/cli init` from your project root. The command installs
shared packages, the source alias, tokens, global styles, and build
configuration. See the [installation guide](/docs/installation) for supported
frameworks.

Continue only after your app completes a production build. StyleX compiles
styles during the build. Installation of its runtime package alone is not
sufficient.

<span id="install-button" />

## 2. Install Button

Run `bunx @yopem-ui/cli add button` from your project root. The CLI installs
Button, required shared files, and dependencies. See the
[Button documentation](/components/button) for usage and API details.

<span id="use-button" />

## 3. Use Button

Import Button from the local file that the CLI installed. The init command maps
`@/*` to `src/*`.

**src/components/save-button.tsx**

```tsx
import { Button } from "@/components/ui/button"

export function SaveButton() {
  return <Button variant="outline">Save changes</Button>
}
```

Render SaveButton. Check that it has padding, a border, a hover state, and a
visible keyboard focus ring.

<span id="customize" />

## 4. Customize it

Use variants for supported visual changes. Use `xstyle` for a local style
override. Use tokens for design changes throughout the app. Edit the copied
source to change component behavior.

**src/components/save-button.tsx**

```tsx
import * as stylex from "@stylexjs/stylex"
import { Button } from "@/components/ui/button"

const styles = stylex.create({ button: { borderRadius: "999px" } })

export function SaveButton() {
  return <Button xstyle={styles.button}>Save changes</Button>
}
```

Keep accessible names, keyboard behavior, disabled states, and focus indicators
when you edit component source.
