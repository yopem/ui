## Initialize project

Start with a React and TypeScript project. Run `bunx @yopem-ui/cli init` from
the project root:

<InstallationCommands />

The init command detects Vite React, React Router, TanStack Router, TanStack
Start, Next.js App Router, or Astro. It supports React Router client mode and
framework mode. It installs shared source, StyleX dependencies, and the Oxlint
plugin. It configures the `@/*` alias, build plugins, and root styles. It keeps
existing project code. If configuration is unsupported or conflicts with
required settings, the command stops with an error. It does not overwrite that
configuration.

If your project has multiple supported frameworks, use `--framework` as shown
above. Accepted values are `vite`, `react-router`, `tanstack-router`,
`tanstack-start`, `next`, and `astro`. The command detects React Router client
mode from `react-router` or `react-router-dom`. It detects framework mode from
`@react-router/dev`.

Vite integrations use Rolldown Babel. Next.js App Router requires Node 24 or
later and webpack. The init command does not support React Router RSC mode,
Next.js Pages Router, or other build tools. The CLI reads registry files from
`https://ui.yopem.com/r` by default. It records installed files in `ui.json`.
The CLI and Oxlint plugin are not published yet. The `bunx` commands work after
both packages are released.

## Verify and continue

Run your project's production build. Check that it completes without StyleX or
CSS extraction errors. Run `bunx oxlint .` to check your app. See the
[lint rules](/docs/lint) for configuration.

Then [add your first component](/docs/getting-started) with the CLI. See the
[CLI guide](/docs/cli) for commands, options, registry settings, and safe
updates.

Static light mode does not need a provider. Add theme switching only if
necessary. See the [theming guide](/docs/theming) for dark mode, custom themes,
and CSP nonces.
