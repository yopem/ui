## 1. Install packages (manual)

Start with a React and TypeScript project. Skip steps 1 and 2 when using the
CLI: init installs dependencies and configures imports. For manual setup,
install shared runtime packages once. Each component page lists its extra
dependencies.

```sh
npm install @stylexjs/stylex@^0.19.0 clsx@^2.1.1
```

<span id="imports" />

## 2. Configure imports (manual)

Map @ to src. Components then live in src/components/ui and import each other
from @/components/ui. Keep the same alias in TypeScript, your bundler, and
StyleX.

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "noEmit": true,
    "allowImportingTsExtensions": true,
    "paths": { "@/*": ["./src/*"] }
  }
}
```

## 4. Configure your framework

CLI init handles the supported setups above. Configurations below are manual
references for custom projects or setup without the CLI.

- [React Router](#react-router) — Client-rendered React Router with Vite.
- [TanStack Router](#tanstack-router) — Client-rendered TanStack Router with
  Vite.
- [TanStack Start](#tanstack-start) — TanStack Start with server rendering.
- [Next.js](#nextjs) — Next.js App Router using webpack.
- [Astro](#astro) — Astro with its React integration.

Using another build tool? Follow its official StyleX setup and keep the @ alias
consistent.

### Vite and Rolldown setup

React Router, TanStack Router, TanStack Start, and Astro use the same StyleX
Babel and PostCSS configuration. Use Vite 8 (Rolldown); no unplugin or Rollup
adapter is needed. Install the build dependencies:

```sh
npm install --save-dev @rolldown/plugin-babel@^0.2.4 @babel/core@^7.29.7 @stylexjs/babel-plugin@^0.19.0 @stylexjs/postcss-plugin@^0.19.0
```

Create `babel.config.cjs` using the `expandLocalSpreads` function from the
[Next.js Babel example](#nextjs) below. Keep the same plugin options, but omit
the `next/babel` preset:

```js
const path = require("node:path")

// Copy expandLocalSpreads from the Next.js example below.
module.exports = {
  plugins: [
    expandLocalSpreads,
    [
      "@stylexjs/babel-plugin",
      {
        aliases: { "@/*": [path.join(__dirname, "src/*")] },
        dev: process.env.NODE_ENV !== "production",
        runtimeInjection: false,
        treeshakeCompensation: true,
        unstable_moduleResolution: { type: "commonJS" },
      },
    ],
  ],
}
```

Create `postcss.config.cjs` so CSS extraction uses those exact Babel plugins:

```js
const babelConfig = require("./babel.config.cjs")

module.exports = {
  plugins: {
    "@stylexjs/postcss-plugin": {
      include: ["src/**/*.{js,jsx,ts,tsx}", "app/**/*.{js,jsx,ts,tsx}"],
      babelConfig: {
        babelrc: false,
        parserOpts: { plugins: ["typescript", "jsx"] },
        plugins: babelConfig.plugins,
      },
      useCSSLayers: true,
    },
  },
}
```

The shared `src/styles/styles.css` already contains `@stylex;`. Import this
single stylesheet in your application entry or document root. The CLI also adds
root theme classes automatically.

### React Router

For client-rendered React Router, replace `reactRouter()` below with `react()`
from `@vitejs/plugin-react` and import `@/styles/styles.css` in `src/main.tsx`.
For React Router **framework mode**, keep `reactRouter()` in the plugin list and
import the same stylesheet in `app/root.tsx` (or `src/root.tsx`). Apply
`themeMarker`, `lightTheme`, and `rootStyles.html` to its `<html>` element and
`rootStyles.body` to `<body>`. The CLI configures both client and framework
mode; RSC mode requires manual setup.

```tsx
import babel from "@rolldown/plugin-babel"
import babelConfig from "./babel.config.cjs"
import { reactRouter } from "@react-router/dev/vite" // framework mode only
import { fileURLToPath } from "node:url"
import { defineConfig } from "vite"

const source = fileURLToPath(new URL("./src", import.meta.url))

export default defineConfig({
  resolve: { alias: { "@": source } },
  plugins: [
    babel({ plugins: babelConfig.plugins }),
    reactRouter(), // omit for client mode; keep your React Vite plugin
  ],
})
```

### TanStack Router

Client-rendered TanStack Router uses the same Vite config, with its router and
React plugins after Babel. Import `@/styles/styles.css` in `src/main.tsx`.

```tsx
import babel from "@rolldown/plugin-babel"
import babelConfig from "./babel.config.cjs"
import react from "@vitejs/plugin-react"
import { tanstackRouter } from "@tanstack/router-plugin/vite"
import { fileURLToPath } from "node:url"
import { defineConfig } from "vite"

const source = fileURLToPath(new URL("./src", import.meta.url))
export default defineConfig({
  resolve: { alias: { "@": source } },
  plugins: [
    babel({ plugins: babelConfig.plugins }),
    tanstackRouter({ target: "react", autoCodeSplitting: true }),
    react(),
  ],
})
```

### TanStack Start

Keep your TanStack Start plugin after Babel. Import `@/styles/styles.css` in
`src/routes/__root.tsx` and apply the root theme classes to `<html>` and
`<body>` (as shown in the [Next.js example](#nextjs)).

```tsx
import babel from "@rolldown/plugin-babel"
import babelConfig from "./babel.config.cjs"
import { tanstackStart } from "@tanstack/react-start/plugin/vite"
import react from "@vitejs/plugin-react"
import { fileURLToPath } from "node:url"
import { defineConfig } from "vite"

const source = fileURLToPath(new URL("./src", import.meta.url))
export default defineConfig({
  resolve: { alias: { "@": source } },
  plugins: [babel({ plugins: babelConfig.plugins }), tanstackStart(), react()],
})
```

### Next.js

This App Router setup uses webpack. Run next dev --webpack and next build
--webpack on Next versions that support those flags. Use babel.config.js:
Next.js does not load .cjs Babel configs. Expand local theme spreads before
StyleX. Do not install the Vite plugin. The manual Babel example assumes
CommonJS; init writes named ESM exports for projects using type: module.

```sh
npm install --save-dev @babel/core@^7.29.7 @stylexjs/babel-plugin@^0.19.0 @stylexjs/postcss-plugin@^0.19.0 autoprefixer@^10.4.0 @types/react@^19.2.18
```

```js
const path = require("node:path")

function expandLocalSpreads({ types: t }) {
  return {
    visitor: {
      Program: {
        enter(program, state) {
          if (
            !state.filename
              ?.replaceAll("\\", "/")
              .endsWith("/src/styles/tokens.stylex.ts")
          )
            return
          program.traverse({
            ObjectExpression(path) {
              path.node.properties = path.node.properties.flatMap(
                (property) => {
                  if (
                    !t.isSpreadElement(property) ||
                    !t.isIdentifier(property.argument)
                  )
                    return [property]
                  const binding = path.scope.getBinding(property.argument.name)
                  const value = binding?.path.node.init
                  if (
                    !t.isObjectExpression(value) ||
                    value.properties.some(t.isSpreadElement)
                  )
                    return [property]
                  return value.properties.map((part) => t.cloneNode(part, true))
                },
              )
            },
          })
        },
      },
    },
  }
}

module.exports = {
  presets: ["next/babel"],
  plugins: [
    expandLocalSpreads,
    [
      "@stylexjs/babel-plugin",
      {
        aliases: { "@/*": [path.join(__dirname, "src/*")] },
        dev: process.env.NODE_ENV !== "production",
        runtimeInjection: false,
        treeshakeCompensation: true,
        unstable_moduleResolution: { type: "commonJS" },
      },
    ],
  ],
}
```

```js
const babelConfig = require("./babel.config.js")

module.exports = {
  plugins: {
    "@stylexjs/postcss-plugin": {
      include: [
        "src/**/*.{js,jsx,ts,tsx}",
        "app/**/*.{js,jsx,ts,tsx}",
        "pages/**/*.{js,jsx,ts,tsx}",
      ],
      babelConfig: {
        babelrc: false,
        parserOpts: { plugins: ["typescript", "jsx"] },
        plugins: babelConfig.plugins,
      },
      useCSSLayers: true,
    },
    autoprefixer: {},
  },
}
```

The shared `src/styles/styles.css` already contains `@stylex;`. Import it in
your root layout.

```tsx
import "@/styles/styles.css"
import * as stylex from "@stylexjs/stylex"
import { lightTheme, rootStyles, themeMarker } from "@/styles/tokens.stylex"

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html
      {...stylex.props(themeMarker, lightTheme, rootStyles.html)}
      data-theme="light"
      lang="en"
    >
      <body {...stylex.props(rootStyles.body)}>{children}</body>
    </html>
  )
}
```

Pages Router projects import the stylesheet in pages/\_app.tsx and apply root
theme classes to Html in pages/\_document.tsx.

### Astro

Install `@astrojs/react`, `react`, and `react-dom` if absent. Author StyleX
styles in React TSX components; use `client:load` only for interactive islands.
Configure Astro's nested Vite plugin list with Rolldown Babel:

```js
import babel from "@rolldown/plugin-babel"
import babelConfig from "./babel.config.cjs"
import react from "@astrojs/react"
import { defineConfig } from "astro/config"
import { fileURLToPath } from "node:url"

const source = fileURLToPath(new URL("./src", import.meta.url))
export default defineConfig({
  integrations: [react()],
  vite: {
    resolve: { alias: { "@": source } },
    plugins: [babel({ plugins: babelConfig.plugins })],
  },
})
```

Import `@/styles/styles.css` in `src/layouts/Layout.astro` frontmatter and apply
`stylex.props(themeMarker, lightTheme, rootStyles.html).className` to `<html>`
and `stylex.props(rootStyles.body).className` to `<body>`.

## 5. Verify and continue

Run your production build. It must finish without StyleX or CSS extraction
errors.

Then follow [Add your first component](/docs/getting-started) to copy, render,
and verify Button.

Static light mode needs no provider. Add switching only if needed. See the
[theming guide](/docs/theming) for dark mode, custom themes, and CSP nonces.
