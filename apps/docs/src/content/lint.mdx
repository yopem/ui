## Rules

The local Oxlint plugin provides four rules:

- **yopem-ui/prefer-ui-primitives**: prefer `Box` over native `div`, `Link` over
  `a`, and semantic UI components where available.
- **yopem-ui/enforce-styling-methods**: allow `xstyle` and consumer `className`
  on imported UI components; reject `css`, inline React style, and direct
  `stylex.props` spreads on those components. Set `className: false` for apps
  styled exclusively with StyleX, as this docs app does.
- **yopem-ui/static-stylex**: require statically analyzable StyleX declarations.
- **yopem-ui/valid-polymorphic-as**: validate native tags on Box and heading
  levels on Heading.

## Configuration

Configure the plugin for your app source. The following policy allows `xstyle`,
but disallows `className` inside the docs app. The copied components still
expose `className` for external integration.

**.oxlintrc.json**

```json
{
  "jsPlugins": [
    {
      "name": "yopem-ui",
      "specifier": "./packages/oxlint-plugin/src/index.ts"
    }
  ],
  "overrides": [
    {
      "files": ["apps/docs/src/**/*.{tsx,jsx}"],
      "rules": {
        "yopem-ui/enforce-styling-methods": [
          "error",
          { "methods": { "className": false } }
        ],
        "yopem-ui/prefer-ui-primitives": "error",
        "yopem-ui/static-stylex": "error",
        "yopem-ui/valid-polymorphic-as": "error"
      }
    }
  ]
}
```

Native framework elements (for example TanStack Router links) can use
`stylex.props(...)`. Imported UI components should use `xstyle` instead of a
StyleX prop spread, so component defaults and consumer styles compose in order.

## Exceptions

`prefer-ui-primitives` accepts `allowElements` for document-shell and resource
tags. Tag replacements are not autofixed: semantics and imports need review.
Registry implementations and non-DOM JSX renderers are outside the docs rule
scope. SVG, MathML, custom elements, and component expressions remain supported;
HTML inside SVG `foreignObject` is still checked. Run `bun run lint` from the
repository root.
