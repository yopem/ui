## What is Yopem UI?

Yopem is a component registry, not a component library dependency. Each
component page contains a live preview, installation dependencies, complete
TypeScript source, usage notes, and generated API details.

- **React 19:** Typed components in your project.
- **Base UI:** Keyboard and screen-reader behavior from accessible primitives.
- **StyleX:** Typed styles beside component code. The compiler converts these
  styles to atomic CSS.

## Why source-owned?

- **Change anything.** Edit markup, behavior, variants, and styles in the same
  file.
- **Copy less.** Copy only the components that you use.
- **Keep control.** Updates change your app only when you choose to copy them.

## How it works

1. Configure the StyleX build transform.
2. Copy the shared theme files once.
3. Choose a component.
4. Install the dependencies shown on its page.
5. Copy each required file to the displayed path in your source directory.
6. Import the local component.
7. Change its source or `xstyle` prop as necessary.

**Use your local component**

```tsx
import { Button } from "@/components/ui/button"

export function SaveButton() {
  return <Button variant="outline">Save changes</Button>
}
```
